# Precedent API

Generated by `tools/gen_api_docs.py` from real responses (arrays trimmed to 2 items, long strings shortened).
Base URL `http://127.0.0.1:8000`. All GET endpoints accept `?redact=1` to mask emails, phone numbers and IBANs.
Statuses: `active` | `superseded` | `amended` | `contested`. Decision types: `explicit` | `implicit`.

## Read

### GET `/api/eval/latest`

Scorecard export written by `python -m eval.run` (shape: `{generated_at, git_commit, banner, targets, global, models, splits: {dev, holdout}}`; each split has metric fields, `decisions_table`, `qa`, `edges`, `conflicts`, `near_decisions`). 404 until an evaluation has run.

## Write

### POST `/api/decisions/{decision_id}/dispute`  body `{"note": "..."}`

Human-in-the-loop feedback. Returns `{"ok": true}`.

### POST `/api/ingest` (multipart field `files`: .eml files, a .zip, or an .mbox)

Starts a run; returns `{"run_id", "files"}`. 409 in demo mode or while a run is in progress.

### POST `/api/ingest/corpus`

Runs the full pipeline over the bundled corpus; returns `{"run_id"}`.

### GET `/api/runs/{run_id}/events` (Server-Sent Events)

Events (each `data:` is JSON with `event`, `run_id`, `ts`): `stage_start {stage}`, `progress {stage, done, total}`, `stage_done {stage, ...stats}`, `decision_found {decision_id|record_id, text, date, status?}`, `run_done {summary}`, `error {message}`. Late subscribers get the full history replayed. `GET /api/runs/{run_id}` returns status + last 50 events.

### POST `/api/demo/load`  body `{"enabled": true|false}`

Loads `demo/cached_run.sqlite` and goes offline (or turns demo mode off). Returns `{"demo_mode": bool}`.
